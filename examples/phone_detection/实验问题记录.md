# Phone Detection 算法实验问题记录

## 1. SIoU 损失函数

### 问题
- IoU 类型参数无法传递：尝试通过 `model.train(iou_type='SIoU')` 传递参数时出现 `SyntaxError: 'iou_type' is not a valid YOLO argument` 错误
- 训练结果异常：CIoU、DIoU、GIoU 三个损失函数的训练结果完全相同，说明参数未生效

### 解决方案
- 在 `ultralytics/cfg/default.yaml` 中添加 `iou_type` 参数定义，使 Ultralytics 框架能够识别该参数
- 检查训练脚本发现 `iou_type` 参数未正确传递，修复后重新训练，确保每个损失函数使用正确的配置

---

## 2. GhostConv / C3Ghost

### 问题
- 模块注册错误：添加新模块时出现 `KeyError: 'C3Ghost'` 错误，模型无法识别新模块

### 解决方案
- 在 `ultralytics/nn/tasks.py` 的导入列表中添加 `C3Ghost` 和 `GhostConv`
- 在 `ultralytics/nn/modules/__init__.py` 中确保导出新模块

---

## 3. LightConv

### 问题
- 维度不匹配：LightConv 不支持 stride 参数，出现 `RuntimeError: Given groups=1, weight of size [3, 128, 1, 1], expected input[1, 16, 128, 128] to have 128 channels, but got 16 channels instead` 错误
- KeyError: 'LightConv'：模型无法识别 LightConv 模块

### 解决方案
- 在 `ultralytics/nn/tasks.py` 的导入列表中添加 `LightConv`
- 修改配置文件，LightConv 仅用于 stride=1 的场景（head 部分），下采样层（stride=2）保留标准 Conv

---

## 4. C2f 变体 (C2fSE/C2fCBAM/C2fECA/C2fPSA)

### 问题
- 模块注册错误：添加新模块（如 C2fCBAM、C2fECA）时出现 `KeyError: 'C2fCBAM'` 错误，模型无法识别新模块
- 数学库未导入：在 ECA 模块中使用 `math.log()` 时出现 `NameError: name 'math' is not defined` 错误
- 维度不匹配：ECA 模块前向传播时出现 `RuntimeError: shape '[1, 128, 1, 1]' is invalid for input of size 129` 错误

### 解决方案
- 在 `ultralytics/nn/tasks.py` 的 `base_modules` 和 `repeat_modules` 集合中注册新模块，并在 `ultralytics/nn/modules/__init__.py` 中导出新模块
- 在 `ultralytics/nn/modules/block.py` 文件顶部添加 `import math` 语句
- 在 ECA 模块的 `forward` 方法中添加维度检查和裁剪逻辑，处理通道数不匹配的情况

---

## 5. 通用问题

### 问题
- 预训练权重加载失败：修改模型结构后，预训练权重的通道数不匹配
- 训练结果不收敛：学习率设置不当导致损失震荡

### 解决方案
- 使用 `model.load()` 而非 `model = YOLO(weights)` 来加载部分匹配的权重
- 调整学习率参数，使用 warmup 策略稳定训练初期
